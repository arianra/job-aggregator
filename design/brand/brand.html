Callback Brand System

One mark, one palette, one voice. Logo: Kom 45 — the receiving bowl turned 45°, the call coming back. Ramps generated in OKLCH (perceptual, constant hue per family). Every step carries a WCAG 2.x contrast role for both themes. Dark theme lives on the night ramp. Typography: Archivo Black display, Inter UI, system mono for data. Not consumed by the app yet — design-system integration is the next step.

Primary lockup: Kom 45 mark + lowercase wordmark, “back” in the accent. Formal SVG assets for both themes live in design/brand/assets/.

Clearspace & minimum size

Clearspace = one bowl-height on all sides. Minimum: 24px digital, 8mm print. At 16px (favicon) use logo-tile.svg, never the open mark.

Use & misuse

  • Use the sanctioned colorways only (light/dark/ink/bone/tile).
  • Use the tile on app icons, avatars, favicons.
  • Do not rotate the mark further (45° is final).
  • Do not recolor outside the ramps.
  • Do not add gradients, shadows, or outlines.
  • Do not stretch or re-stroke the bowl.

02 · Color

Six families, OKLCH-generated, 500 = brand value. Each chip shows its contrast roles: L = on light ground (bone), D = on dark ground (night-950). AA = text-safe (≥4.5), AA-LG = large text / UI graphics (≥3), gfx = graphics only.

05 · Contrast

Roles are computed, not eyeballed — WCAG 2.x relative luminance and contrast ratio (canonical definition: w3c/wcag · guidelines/terms/20/relative-luminance):

L = 0.2126·R + 0.7152·G + 0.0722·B  (sRGB channels linearized)
ratio = (Llighter + 0.05) / (Ldarker + 0.05)
AA text ≥ 4.5 · AA large/UI ≥ 3.0 · below = graphics only

Rules that follow: sun-500 never sets text on light grounds (1.38:1) — it is the notification dot. vermilion-600 is the light-theme text accent (4.94:1); vermilion-500 is the dark-theme accent (4.99:1). Muted text = grey-600 on light (4.49:1, AA-LG; use grey-700 when AA is required), grey-400 on dark (6.5:1, AA).

06 · Icon language

The mark’s grammar is the icon system. Future app icons (resume, lint, tracker, export) are drawn on the same grid so the family reads as one hand.

Canvas

512 grid, safe area 64 inset. Marks may touch the safe edge, never the canvas edge.

Stroke

60 units (≈11.7% of canvas), constant across the family. Filled shapes = stroke-width equivalents.

Angles

Multiples of 45° only. Joins miter, caps flat. No curves except the sun dot.

Accent

At most one sun dot (r=46) per icon — the notification voice. Never two accents.

Color

One family per icon: vermilion (action), ultramarine (info), grey (disabled). Dark theme lifts one step.

Silhouette test

Every icon must survive 32px on both grounds before it ships — same gate the logo passed.
